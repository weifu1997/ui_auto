# 多人协作远程变更感知（COL-01）

## 背景

`ServerWorkspaceSynchronizer` 仅在挂载/焦点变化时拉取工作区数据，没有连续轮询
契约；成员可能基于陈旧数据工作，直到出现版本冲突或手动刷新才感知到其他成员的提交。

## 目标

- 其他成员已提交的修改在文档化时限（30s）内自动可见。
- 本地未提交（dirty）草稿在任何自动刷新中都不被覆盖。
- 版本冲突发生时，展示冲突的更新者与更新时间。

## 非目标

- 不实现实时 WebSocket/SSE 推送。
- 不改变冲突解决的产品语义（复制/刷新远端/重新提交）。
- 不改变后端资源版本与 RBAC 契约。
