## 4. 遇到的问题与处理

1. **StrictMode 下本地面板卡在 loading**：`mounted` ref 在 React StrictMode 双调用 effect 的第一次 cleanup 被置 false，健康检查/会话创建的回调不再更新状态，面板一直显示 Spin。移除 mounted 守卫后正常（真实应用 main.tsx 使用 StrictMode，自测暴露）。
2. **自测种子脚本每次导航清空本地 store**：导致环境创建后导航到元素页时环境丢失。改为仅首次注入（localStorage 已有则跳过）。
3. **e2e management-and-run 偶发失败**：antd Select 键盘选择（ArrowDown+Enter）时序抖动，与本轮改动无关；单独复跑与全量复跑均通过（27/27）。
4. **本机 Worker 有头浏览器 + 外部站点创建会话耗时**（约 8s）：面板自动创建 + 轮询等待，属预期。
