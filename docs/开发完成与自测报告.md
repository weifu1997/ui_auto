## 已交付能力

- Platform 服务按认证、工作空间、项目、资源、版本、自动化、模板和审计拆分，并通过有序 SQLite 迁移升级。
- HttpOnly Cookie 会话、退出、账号启停、密码重置、会话失效、角色权限和最后一位工作空间所有者保护。
- 服务端资源唯一数据源、资源级版本号和冲突恢复操作；项目、数据集、计划任务、Webhook、通知通道支持归档/恢复策略。
- 草稿、提交、审核、发布、回滚、冻结快照和审计；已发布版本不可变。
- ManagedRunner 本机并发队列、恢复/取消/重试策略、元素真实浏览器验证和受保护截图产物；密钥脱敏。
- 数据集逐行运行、Cron/Webhook/通知安全校验、通知主机允许列表和私有地址显式开关。
- 内部模板冻结、脱敏、搜索/分类/排序、收藏、更新、软删除、应用时 ID 重写，以及模板/冲突端到端闭环。
- 角色化工作台、加载/空态/权限/冲突/失败/危险操作反馈，桌面和移动布局回归；生产页面不显示 Worker/Agent 开发术语。
- Windows WinSW 配置、安装/升级/回滚/备份/恢复/保留和 readiness/liveness 检查脚本，固定 Playwright 浏览器目录和密钥配置。
