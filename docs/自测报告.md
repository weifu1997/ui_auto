## 4. 遇到的问题与处理

1. **`page.evaluate` 注入脚本被 tsx 改写导致 `__name is not defined`**：真实 Agent 的 enablePicker 首次在自动化中触发时暴露；改为纯 JS 字符串注入，问题解决（含单测/冒烟覆盖）。
2. **调试会话占用单并发节点，元素验证无法调度**：先结束调试会话（stop）再运行验证，验证正常完成。
3. **前端 CSP 限制 API 端口**：自测必须使用默认端口 8787/4173（CSP `connect-src` 仅放行 127.0.0.1:8787）。
4. **antd 下拉动画竞态**：调试会话创建改为由采集面板自动创建（也是「从页面获取」的预期行为），避免手工下拉点击的动画竞态。
5. **同步偶发 409（DOCUMENT_VERSION_CONFLICT）**：本地修改与远端版本冲突时同步器自动重试并最终一致（`platformSyncStatus=synced`），按既有冲突处理策略处理，非代码缺陷。
6. **验证结果 count=0**：外部站点为客户端渲染 SPA，验证浏览器在 `domcontentloaded` 即计数导致偶发未渲染；结论如实记录为「未找到匹配元素/未验证」，不误判为通过（符合 4.3 外部站点策略）。
