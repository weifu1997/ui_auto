# 决策：内网部署形态与 Platform 裁剪（方案 C）

> 状态：已确定（2026-08-13）。依据本决策创建了任务 `08-13-trim-agent-remote-exec` 规划裁剪实施。
> 相关代码：`server/index.ts`（监听/密钥/legacy 守卫）、`server/platform-*.ts`（平台服务）、`server/managed-runner.ts`（部署机执行器）、`agent/index.ts`（远程 Agent）、`src/pages/*`（平台页面）、`src/platform-api.ts`。

---

## 1. 部署目标（已确认）

| 维度 | 结论 |
| --- | --- |
| 部署位置 | 一台内网电脑（服务常驻） |
| 访问方式 | **局域网网页访问**：浏览器从内网其他电脑打开 `http://<部署机IP>:8787`（监听 0.0.0.0） |
| 执行位置 | **仅部署机执行**：浏览器自动化（Chromium）只在部署机上跑 |
| 自动能力 | **需要**：定时回归（Cron）、失败通知（飞书/钉钉/Webhook）、数据集参数化——均为 platform-only |

## 2. 现状（证据）

- 构建后的前端通过同源 `/api` 调用 Python Platform 服务，服务静态托管 `dist/`；局域网浏览器访问部署机 IP 即可。
- `npm run start` 自动设置生产环境并要求 `PLATFORM_SECRET_KEY`；默认仅监听 loopback，只有显式设置 `AUTOFLOW_LISTEN_HOST=0.0.0.0` 才暴露到局域网。
- legacy Worker API（`/api/projects/*`）和 local 产品模式已从运行时移除，部署形态只有 Platform（登录 + 密钥守卫）。
- 平台运行由 `ManagedRunner` 在部署机本机执行，与"仅部署机执行"完全吻合。
- Agent（`agent/index.ts` 996 行）用于**多机分布式执行**：注册令牌、WebSocket 外连、心跳、租约、工件上传；本项目不需要多机执行。
- 定时/通知/数据集/治理（schedules、webhook_triggers、notification_channels、datasets、analytics）全部只在 platform 实现，local 模式没有等价物。

## 3. 决策：方案 C（保留 Platform 核心 + 裁剪 Agent 远程执行）

否决的备选：

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| A. 保留 platform 完整不裁剪 | 否 | Agent 远程执行（约 2,000–3,000 行：agent/ 996 + WS/agents 端点 + 租约/心跳/重连 + 远程调试会话链路）在单机部署形态下是死代码，且是复杂度最高的协议面 |
| B. 完全砍掉 platform | 否 | 定时回归/通知/数据集/治理是确认需要的 platform-only 能力；局域网访问也需要登录/RBAC 与密钥守卫；砍掉后 production 形态需整体重定义 |

**方案 C 保留**：认证/会话、工作空间/RBAC、集中式项目文档、发布/修订/回滚、密钥加密、数据集、定时/Webhook、通知渠道、治理分析、模板库、ManagedRunner（部署机执行）。

**方案 C 裁剪**：Agent 客户端（`agent/`）、Agent 服务端端点（`/api/agents*`、agent-tokens、agent-bindings、run_leases、WS upgrade）、远程调试会话链路（`debug_sessions` 相关端点/表/页面），以及与之绑定的 UI（AgentsPage 的 Agent 管理部分、DebugSessionsPage）与测试。

裁剪范围的完整清单与开放设计点见任务 `08-13-trim-agent-remote-exec` 的 `prd.md` / `design.md`。

## 4. 部署参数

```bash
npm run build
set AUTOFLOW_LISTEN_HOST=0.0.0.0
set AUTOFLOW_CORS_ORIGINS=http://<部署机内网IP>:8787
set PLATFORM_SECRET_KEY=<长随机密钥>
npm run start
```

- `npm run start` 自动检查构建产物和密钥并设置 `NODE_ENV=production`，无需手动设置。
- 验证闭环：网页编排 → 部署机执行 → 定时回归 → 飞书通知。
